# Monarch Monarch III

Next.js App Router + TypeScript + Canvas 2D로 제작한 실시간 전략 게임 프로토타입입니다.

네 왕국이 물길과 다리로 연결된 전장에서 병력을 출격시키고, 적 왕국의 성을 함락하는 게임입니다. 플레이어는 파란색 **청람 왕국**을 지휘합니다.

모나크모나크를 참고한 비공식 학습용 프로젝트이며, 현재 지도와 전장 그래픽은 SVG와 Canvas 코드로 그립니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 에 접속합니다.

프로덕션 빌드 및 실행:

```bash
npm run build
npm start
```

## 화면 구성

### 메인 `/`

- 검은 배경의 타이틀 화면
- 새로운 게임: 월드 화면으로 이동
- 이어서 하기: 현재 비활성화
- 종료: 빈 페이지로 이동

### 월드 `/world`

- SVG로 그린 월드 지도
- 지도 위 깃발을 클릭하면 스테이지 선택창 표시
- 출전 버튼을 누르면 전장으로 이동
- 현재 플레이 가능한 스테이지는 **네 왕국의 교차로** 1개

### 전장 `/game`

- Canvas 2D 기반 아이소메트릭 전장
- 산악 배경, 섬, 물길, 목교, 숲, 성과 병사 표시
- 청람·홍염·황금·녹림의 네 왕국 전투
- 왼쪽 도구 모음과 상단 왕국 상태 표시

## 조작법

| 조작 | 기능 |
| --- | --- |
| ▶ / Ⅱ | 전투 시작 또는 일시정지 |
| 적 성 클릭·터치 | 해당 성으로 병사 최대 6명 출격 |
| 1× / 2× | 전투 진행 속도 변경 |
| ⚑ | 왕국 현황 열기·닫기 |
| 왕국 현황의 왕국 선택 | 공격 대상 선택 및 전투 중 출격 |
| ? | 조작 방법 열기·닫기 |
| ↻ | 전장 초기화 |
| ↶ | 월드 화면으로 이동 |

## 전투 규칙

- 각 왕국은 성 체력 **100**, 대기 병력 **18명**으로 시작합니다.
- 게임 시간 기준 **2.5초마다 병력 1명**을 보충합니다.
- 대기 병력은 왕국당 최대 **36명**입니다.
- 한 번 출격할 때 대기 병력 중 최대 **6명**을 보냅니다.
- 적 왕국은 게임 시간 기준 **8초마다 자동 출격**을 시도합니다.
- 병사는 물과 나무가 있는 타일을 피해서 이동합니다.
- 이동 중 적 병사와 만나면 자동으로 전투합니다.
- 적 성에 도착하면 자동으로 공격합니다.
- 성이 함락되면 해당 왕국의 병사도 제거됩니다.
- 적 성을 모두 함락하면 승리합니다.
- 청람 왕국의 성이 함락되면 패배합니다.
- 2배속에서는 이동, 전투, 병력 보충과 적 출격이 함께 빨라집니다.

## 프로젝트 구조

```text
src/
└── app/
      ├── layout.tsx
      ├── globals.css
      ├── page.tsx
      ├── page.module.css
      ├── world/
      │     ├── page.tsx
      │     └── page.module.css
      └── game/
            ├── page.tsx
            └── page.module.css
```

| 파일 | 역할 |
| --- | --- |
| `src/app/page.tsx` | 메인 타이틀과 메뉴 |
| `src/app/page.module.css` | 메인 화면 스타일 |
| `src/app/world/page.tsx` | SVG 월드 지도와 스테이지 선택 |
| `src/app/world/page.module.css` | 월드 화면과 선택창 스타일 |
| `src/app/game/page.tsx` | 전장 생성, 경로 탐색, 전투, Canvas 렌더링 |
| `src/app/game/page.module.css` | 전장 도구 모음, 상태창, 결과창 스타일 |

## 구현 방식

- React 클라이언트 컴포넌트에서 Canvas를 초기화합니다.
- `requestAnimationFrame`으로 게임 루프를 실행합니다.
- 실제 게임 상태는 `useRef`에 보관합니다.
- 화면에 표시하는 React 상태는 일정 간격으로 갱신합니다.
- BFS 경로 탐색으로 병사의 이동 경로를 계산합니다.
- 객체의 위치를 기준으로 그리기 순서를 정해 전장의 앞뒤 관계를 표현합니다.
- 화면 스타일은 CSS Modules로 분리합니다.

## 현재 제한 사항

- 싱글 플레이와 스테이지 1개만 지원합니다.
- 저장 및 불러오기 기능은 구현하지 않았습니다.
- 새로고침하거나 전장 화면을 벗어나면 진행 상황이 초기화됩니다.
- 개별 병사 선택과 직접 이동 명령은 지원하지 않습니다.
- 건설, 자원 생산, 유닛 종류별 능력, 사운드는 구현하지 않았습니다.
- 종료 메뉴는 브라우저 탭을 닫는 대신 빈 페이지로 이동합니다.

## 확장 계획
