# Maple Clone

Next.js 16 (App Router) + Canvas 2D로 만든 메이플스토리풍 횡스크롤 프로토타입입니다.
실제 메이플스토리의 이미지/스프라이트/로고 등 저작물은 사용하지 않았고, 캔버스로 직접 그린 오리지널 그래픽입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 조작법

- 이동: 방향키(←→) 또는 A/D
- 점프: Space, W, ↑
- 몬스터는 위에서 밟으면 처치(+100점), 옆에서 부딪히면 HP 1 감소
- 코인 획득 시 +10점
- 맵 끝(오른쪽)까지 도달하면 클리어

## 구조

- `app/page.tsx` — 진입점, Game 컴포넌트를 ssr:false로 동적 로드 (캔버스는 브라우저 전용)
- `components/Game.tsx` — 게임 로직 전체 (물리, 충돌, 카메라, 렌더링)이 담긴 클라이언트 컴포넌트

## 확장 아이디어

- 실제 이미지 스프라이트/스프라이트시트로 교체 (지금은 도형으로 그린 캐릭터)
- 여러 맵(포탈로 이동), 저장/로드
- 스킬 시스템, 레벨업, 인벤토리
- 사운드 이펙트/BGM
